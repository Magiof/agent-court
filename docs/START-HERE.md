# Agent Court (에이전트 조정) 시작하기

**한국어** · [English](START-HERE.en.md)

내 Claude Code·Codex의 작업 상태를 조선시대 마을에서 보는 개인용 앱입니다. 자신의 컴퓨터에 설치하고 기존 계정과 작업 방식을 그대로 사용합니다.

[← 프로젝트 소개](../README.md)

## 설치하고 연결하기

Node.js 20 이상과 사용할 Claude Code 또는 Codex가 먼저 설치되어 있어야 합니다. 현재 실제 설치를 확인한 환경은 macOS입니다. 설치 도구는 Linux도 지원하며 Windows는 지원하지 않습니다.

GitHub 소스로 설치하려면 원하는 위치에서 다음을 실행하세요.

```bash
git clone https://github.com/Magiof/agent-court.git
cd agent-court
npm install --global .
```

배포 파일을 받았다면, 파일을 저장한 폴더에서 다음 방법으로 설치할 수도 있습니다.

```bash
npm install --global ./agent-court-0.2.0.tgz
```

두 도구를 함께 연결하려면:

```bash
agent-court connect both
```

하나만 사용한다면 `both` 대신 `claude` 또는 `codex`를 지정하세요.

연결 도구는 기존 설정을 유지하며 작업 기록기를 추가합니다. 바뀌는 파일 옆에 백업을 남깁니다. Claude Code는 새 세션을 열어 연결 설정을 읽게 해 주세요.

Codex 데스크톱 앱에서는 앱의 Hooks 설정에서 새 기록기를 확인하고 신뢰하세요. CLI를 사용하는 경우에는 `/hooks`로 확인합니다. 연결 도구는 이 검토 과정을 건너뛰지 않습니다. 신뢰한 뒤 새 로컬 세션을 시작하세요. 앱 안의 신뢰 확인 기능은 [공식 앱 변경 안내](https://learn.chatgpt.com/docs/changelog)에, 공통 설정 위치는 [Codex Hooks 안내](https://learn.chatgpt.com/docs/hooks)에 설명되어 있습니다.

`agent-court` 명령은 연결과 맵 실행을 관리합니다. Codex 작업은 평소 쓰던 CLI 또는 데스크톱 앱에서 계속하세요. 현재 기록기는 같은 컴퓨터에서 실행하는 로컬 작업용이며, 클라우드나 다른 컴퓨터에서 실행하는 작업은 연결 대상에 포함되지 않습니다.

검증 범위: 임시 환경에서 전역 설치, 기존 설정 보존, 양쪽 기록기 실행, 서버·맵 반영과 연결 해제를 확인했습니다. Codex CLI 0.154.0의 설정 인식도 확인했습니다. **Codex 데스크톱 앱에서 실제 작업을 실행해 맵까지 반영되는지는 아직 검증하지 않았습니다.**

## 맵 켜기

```bash
agent-court start
```

브라우저에서 `http://localhost:4545`를 열고 평소처럼 작업하세요. 기록기가 전달받은 조회·수정·테스트·승인 대기·응답 완료 이벤트에 따라 인물이 관청을 이동합니다. 명부에는 Claude Code와 Codex를 구분해 표시합니다.

개인용 설치는 작업 관찰용입니다. 작업 지시와 권한 승인은 원래 쓰던 Claude Code·Codex에서 진행하세요. 맵을 끌 때는 맵을 켠 터미널에서 Ctrl+C를 누릅니다.

## 저장되는 정보

시각, 세션 ID, 작업 폴더, 도구 이름, 작업 종류를 자기 컴퓨터의 `~/.agent-court/data/`에 저장합니다. 새 기록 폴더가 없고 기존 `~/.claude-farm/data/`가 있으면 기존 폴더를 자동으로 재사용합니다. 기존 기록은 이동하거나 삭제하지 않습니다. 연결 명령의 `Records:` 출력에서 실제 기록 폴더를 확인할 수 있습니다.

개인용 기록기는 프롬프트·대화 본문·명령 원문·패치 내용·파일 내용·도구 출력을 새로 저장하지 않습니다. 기존 폴더를 재사용해도 이전에 저장된 기록의 내용은 바꾸지 않습니다.

대시보드 서버는 `127.0.0.1`에서만 열립니다. 작업 기록을 공동 서버로 보내는 기능은 없습니다. 화면 글꼴을 위해 Google Fonts를 불러오며, 연결한 Claude Code·Codex 자체의 서비스 통신은 기존과 같습니다.

서버가 꺼져 있어도 연결된 기록기는 기록을 남기고, 맵을 다시 켜면 최근 12시간을 복원합니다. 오래된 무소식 세션은 맵에서 사라집니다.

기록기와 맵은 추가 모델 호출을 하지 않습니다. 기록기·서버·브라우저는 CPU와 메모리를 사용하고, 이벤트 기록은 디스크에 쌓입니다. 자원 사용량은 작업 빈도와 환경에 따라 달라지며 이번 배포에서는 별도로 측정하지 않았습니다.

## 연결 해제

```bash
agent-court disconnect both
```

하나만 해제하려면 `both` 대신 `claude` 또는 `codex`를 지정하세요. 이 앱이 추가한 기록기만 제거하며 다른 훅과 기존 설정, 저장된 기록은 유지합니다. Codex에서 이미 신뢰한 정의가 변경되면 앱의 Hooks 설정 또는 CLI의 `/hooks`에서 확인하세요.

## 화면에 세션이 안 나올 때

- 새 세션에서 간단한 작업을 시작해 보세요. 연결 전에 끝난 작업은 자동으로 가져오지 않습니다.
- Codex는 앱의 Hooks 설정 또는 CLI의 `/hooks`에서 기록기를 신뢰했는지, 훅이 활성화되어 있는지 확인하세요. 훅을 지원하는 버전과 로컬 작업이 필요합니다. Codex CLI 0.154.0에서 설정 인식을 검증했습니다.
- Claude Code는 `/hooks`에서 기록기가 등록되었는지 확인하세요. 공식 [Claude Code Hooks 안내](https://code.claude.com/docs/en/hooks)를 참고할 수 있습니다.
- Node.js 설치 위치나 앱 설치 폴더가 바뀌었다면 `connect`를 다시 실행해 경로를 갱신하세요.
- 다른 앱이 4545번 포트를 사용 중이면 `agent-court start --port 4547`로 켜고 `http://localhost:4547`를 여세요.

변경 전에 설정 계획만 확인하려면 `agent-court connect both --dry-run`을 사용할 수 있습니다.
별도 설정 위치가 필요하면 `--claude-home`, `--codex-home`, `--data-dir`를 지정하세요. 사용자 지정 기록 폴더를 연결할 때 썼다면 맵을 켤 때도 같은 `--data-dir`를 지정해야 합니다.
