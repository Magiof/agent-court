# Assets and external fonts

[한국어](THIRD-PARTY-NOTICES.md) · **English**

This package includes the active map, character assets, and user guides. It excludes development activity logs, tokens, personal attachments, reference images, and screenshots containing real work.

- The current map (`map-concept-v1.png`) and seven character sheets (`sprites/v2/*.png`) were generated with OpenAI ImageGen for this project.
- The documentation banner is an SVG created for the project. The demo screenshot uses fictional sessions.
- The dashboard loads Gowun Batang and Song Myung from Google Fonts. Font files are not bundled with this package.

Earlier Kenney images, the Galmuri font, old maps, buildings, props, and character sheets are no longer used by the dashboard and have been removed from the project and distribution package.
